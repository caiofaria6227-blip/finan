Cópia de segurança (backup)
Os dados ficam só neste celular. Se o celular quebrar, for trocado ou o navegador for limpo, os dados se perdem. Faça um backup toda semana e guarde o arquivo no Google Drive ou mande para o seu próprio WhatsApp.

  2. Toque nos três pontinhos ⋮ no canto de cima.
